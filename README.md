# Pallet Packer 📦🚚

Jednoduchý vizuální 3D plánovač pro skládání palet do dodávek a náklaďáků. Vzniklo jako víkendový projekt pro rychlé ověření, co se do auta reálně vejde a jak náklad poskládat bez zbytečného přeměřování na rampě.

### Co to umí
* **3D náhled v reálném čase** – přehledné rozmístění palet v ložném prostoru auta
* **Nezávislé rozměry** – podpora klasických formátů (EUR 1 atd.) i atypických rozměrů zboží
* **Pravidla stohování** – nastavení nosnosti a možnosti vrstvení pro každý náklad
* **Export do PNG** – rychlé stažení 3D pohledu i přehledného nákladového listu

### Technologie
* React + TypeScript
* Three.js / React Three Fiber
* Tailwind CSS
